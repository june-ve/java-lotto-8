# 로또

---

## 🧩 프로젝트 개요

사용자가 입력한 구입 금액에 따라 여러 장의 로또를 발행하고,
입력된 당첨 번호 및 보너스 번호와 비교하여
등수별 당첨 개수와 총 수익률을 계산해 출력하는 콘솔 기반 로또 시뮬레이터.

---

## 📜 기능 요구사항

- 로또 번호의 숫자 범위는 **1~45**까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 **6개의 숫자**를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 **보너스 번호 1개**를 입력받는다.
- 로또 1장의 가격은 **1,000원**이다.
- 구입 금액을 입력하면 해당 금액만큼 로또를 발행한다.
- 당첨 번호와 보너스 번호를 입력받아 당첨 내역과 **수익률**을 출력한다.
- 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고,
`[ERROR]`로 시작하는 에러 메시지를 출력 후 **그 부분부터 입력을 다시 받는다.**


---

## 💰 당첨 기준 및 상금

| 등수 | 조건 | 상금 |
| --- | --- | --- |
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

---

## 🍀 기능 목록

### 1. 도메인 규칙 정의
- [x]  로또 번호는 1~45 사이의 숫자여야 한다.
- [x]  로또 번호는 중복되지 않아야 한다.
- [x]  로또 번호는 6개여야 한다.

### 2. 당첨 조건 정의
- [x]  일치 개수와 보너스 번호 여부에 따라 등수를 판단한다.
- [x]  1~5등의 기준과 상금 정보를 정의한다.

### 3. 당첨 번호 구성
- [x]  당첨 번호와 보너스 번호를 입력받아 저장한다.
- [x]  보너스 번호가 당첨 번호와 중복되면 예외를 발생시킨다.
- [x]  로또 한 장과 비교하여 일치 개수를 계산하고 등수를 반환한다.

### 4. 로또 발행 및 구입 로직
- [x]  구입 금액으로 구매 가능한 로또 개수를 계산한다.
- [x]  1~45 범위의 중복되지 않는 6개의 숫자를 무작위로 생성한다.
- [x]  발행된 로또 목록을 반환한다.

### 5. 당첨 결과 및 수익률 계산
- [x]  발행된 로또 목록과 당첨 번호를 비교해 등수별 개수를 계산한다.
- [x]  총 당첨 금액을 계산한다.
- [x]  수익률을 계산하고 소수점 둘째 자리에서 반올림한다.

### 6. 프로그램 흐름 제어
- [x]  구입 금액, 당첨 번호, 보너스 번호를 입력받는다.
- [x]  당첨 통계와 수익률을 출력한다.
- [x]  잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 다시 입력받는다.

| `ProfitCalculator` | 계산기 | 총 상금 및 수익률 계산 |
