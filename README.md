# 로또

---

## 기능 목록

### 1. 도메인 규칙 정의
- [ ]  로또 번호는 1~45 사이의 숫자여야 한다.
- [ ]  로또 번호는 중복되지 않아야 한다.
- [ ]  로또 번호는 6개여야 한다.

### 2. 당첨 조건 정의
- [ ]  일치 개수와 보너스 번호 여부에 따라 등수를 판단한다.
- [ ]  1~5등의 기준과 상금 정보를 정의한다.

### 3. 당첨 번호 구성
- [ ]  당첨 번호와 보너스 번호를 입력받아 저장한다.
- [ ]  보너스 번호가 당첨 번호와 중복되면 예외를 발생시킨다.
- [ ]  로또 한 장과 비교하여 일치 개수를 계산하고 등수를 반환한다.

### 4. 로또 발행 및 구입 로직
- [ ]  구입 금액으로 구매 가능한 로또 개수를 계산한다.
- [ ]  1~45 범위의 중복되지 않는 6개의 숫자를 무작위로 생성한다.
- [ ]  발행된 로또 목록을 반환한다.

### 5. 당첨 결과 및 수익률 계산
- [ ]  발행된 로또 목록과 당첨 번호를 비교해 등수별 개수를 계산한다.
- [ ]  총 당첨 금액을 계산한다.
- [ ]  수익률을 계산하고 소수점 둘째 자리에서 반올림한다.

### 6. 프로그램 흐름 제어
- [ ]  구입 금액, 당첨 번호, 보너스 번호를 입력받는다.
- [ ]  당첨 통계와 수익률을 출력한다.
- [ ]  잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 다시 입력받는다.
